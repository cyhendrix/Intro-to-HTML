# Intro to HTML Practice Lab

Focused practice for HTML starter code and paragraph tags.

## Publish on GitHub Pages

1. Upload `index.html` to the root of the `Intro_To_HTML` repository.
2. Open **Settings > Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select **main** and **/(root)**, then click **Save**.

The site includes drag-and-drop starter code, tag identification, paragraph debugging, a paragraph creation check, immediate feedback, randomized practice, and locally saved points.
